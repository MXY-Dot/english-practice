# Elementary Practice

Сайт с заданиями для ученика и учителя по 12 юнитам уровня Elementary
(в порядке тем учебника English File 4th Edition Elementary).

- **36 тестов** (по уроку: 1A, 1B, 1C … 12C), в каждом **50 заданий** вперемешку:
  35 практических (грамматика, лексика, произношение, аудирование, говорение, письмо),
  10 вопросов по теории грамматики и 5 небольших текстов на разбор (каждое 10-е задание). Всего 1800 заданий.
- Половина заданий требует вписать ответ, а не выбрать вариант.
- Символы звуков (например, /ʌ/) — это кнопки 🔊: нажмите, чтобы услышать слово с этим звуком.
- **Оформление** (кнопка ❄️/🌸/☀️/🍂/🎄 вверху справа): зима, весна, лето, осень, Новый год (с гирляндой) и ночная тема.
  В режиме «Авто» сезон выбирается по дате (Новый год — с 20 декабря по 14 января), а ночная тема включается с 19:00 до 7:00.

## Ученики и учителя

- **Каждый придумывает себе пароль** при регистрации.
- **Ученик** регистрируется, делает тесты (по 10 заданий на странице) и отправляет учителю.
- **Учитель** регистрируется с **кодом учителя** (его задаёт владелец сайта, см. ниже), затем в блоке
  «Мои ученики → Добавить ученика» выбирает своих учеников.
- Ученика может выбрать **только один учитель**: после этого он пропадает из списка у остальных учителей.
  Если два учителя нажмут одновременно, база данных пропустит только первого.
- Учитель видит и проверяет **только своих** учеников: меняет балл за любое задание (✓ / ½ / ✗),
  пишет исправление и комментарий, ставит оценку (2–5) или возвращает работу на доработку.
- Ученик видит оценку, правильные ответы, исправления, комментарии и имя своего учителя.

## Как устроено аудио

- **Фразы, диалоги и образцы для говорения** озвучены заранее естественными нейроголосами
  (открытая модель Kokoro, британские мужские и женские голоса; в диалогах у каждого героя свой голос).
  Файлы лежат в `audio/`. Если файла нет — включается синтез речи браузера.
- **Отдельные слова**: записи живых носителей из бесплатного [Free Dictionary API](https://dictionaryapi.dev),
  если записи нет — нейроголос.
- **Говорение**: ученик записывает себя через микрофон, учитель слушает запись.

Если вы добавили или изменили задания с аудио, выполните `npm install` (один раз) и `npm run voices`:
озвучатся только новые фразы. При первом запуске скачивается модель (~90 МБ), на сайт она не попадает.

MP3-файлы из учебника на сайт не выкладываются: на GitHub Pages они были бы доступны всем.

## Запуск на своём компьютере

Нужен Node.js 18+.

```bash
npm run serve        # http://localhost:8080
```

Без настройки сайт работает в **демо-режиме**: данные хранятся только в этом браузере.
Вход по имени и паролю: при первом входе аккаунт создаётся с этим паролем.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (кроме `node_modules`).
2. В репозитории откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Подключение общей базы (Supabase), чтобы ученики и учителя работали с разных устройств

GitHub Pages умеет показывать только файлы, поэтому для общих данных нужен бесплатный Supabase.

1. Зарегистрируйтесь на <https://supabase.com> и создайте проект (**New project**).
2. Откройте файл `supabase/schema.sql` и замените `teacher-2026` на свой секретный **код учителя**.
3. В Supabase откройте **SQL Editor → New query**, вставьте содержимое файла и нажмите **Run**.
4. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon public**.
5. Вставьте их в `js/config.js`:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
   Ключ `anon` можно хранить в публичном репозитории: доступ к данным защищён правилами из `schema.sql`.
6. (Рекомендуется) **Authentication → Providers → Email**: выключите **Confirm email**, чтобы входить сразу после регистрации.
   Если подтверждение оставить включённым, в **Authentication → URL Configuration** укажите адрес сайта на GitHub Pages.
7. Сообщите код учителя только учителям. Учитель на сайте: **Регистрация → Я учитель**, вводит код и придумывает пароль.

Сменить код учителя позже (старые учителя останутся учителями):
```sql
update public.app_settings set value = 'новый-код' where key = 'teacher_code';
```

## Проверка заданий и сайта

```bash
npm run check   # тесты проверки ответов + проверка всех 1800 заданий
npm run e2e     # браузерный тест: все 36 тестов, аккаунты, ученик → учитель → ученик, темы
```

## Как добавить или изменить задания

Задания лежат в `data/units/u01.js` … `u12.js`. Типы заданий описаны в `CLAUDE.md`.
После изменений запустите `npm run check`: в каждом уроке должно быть 35 практических заданий, 10 по теории и 5 текстов.
Не вставляйте и не удаляйте задания в середине урока, по которому ученики уже работают: ответы привязаны к номеру задания в группе.
