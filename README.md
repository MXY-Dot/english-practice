# Elementary Practice

Сайт с заданиями для ученика и учителя по 12 юнитам уровня Elementary
(в порядке тем учебника English File 4th Edition Elementary).

- **36 тестов** (по уроку: 1A, 1B, 1C … 12C), в каждом **40 заданий** вперемешку:
  26 практических (грамматика, лексика, произношение, аудирование, говорение, письмо),
  10 вопросов по теории грамматики и 4 небольших текста на разбор (каждое 10-е задание). Всего 1440 заданий.
- Около половины заданий требуют вписать ответ, а не выбрать вариант.
- Символы звуков (например, /ʌ/) — это кнопки 🔊: нажмите, чтобы услышать слово с этим звуком.
- **Оформление** (кнопка ❄️/🌸/☀️/🍂 вверху справа): зима, весна, лето, осень и ночная тема.
  В режиме «Авто» сезон выбирается по текущему месяцу, а ночная тема включается с 19:00 до 7:00.
- **Ученик** выполняет тест (по 10 заданий на странице) и отправляет работу учителю.
- **Учитель** видит все работы, автопроверка уже выставлена. Учитель может изменить балл за любое задание (✓ / ½ / ✗),
  написать исправление и комментарий к каждому заданию, поставить оценку (2–5) или вернуть работу на доработку.
- **Ученик** видит оценку, правильные ответы, исправления и комментарии учителя.

## Как устроено аудио

- **Отдельные слова** (задания на звуки и ударение): записи живых носителей из бесплатного
  [Free Dictionary API](https://dictionaryapi.dev). Если записи нет — включается синтез речи браузера.
- **Фразы и диалоги** (аудирование): синтез речи браузера (лучше всего звучит в Chrome и Edge).
- **Говорение**: ученик записывает себя через микрофон, учитель слушает запись.
  В Chrome дополнительно показывается распознанный текст.

MP3-файлы из учебника на сайт не выкладываются: на GitHub Pages они были бы доступны всем.

## Запуск на своём компьютере

Нужен Node.js 18+.

```bash
npm run serve        # http://localhost:8080
```

Без настройки сайт работает в **демо-режиме**: данные хранятся только в этом браузере.
Ученик входит по имени, учитель — по PIN (по умолчанию `1234`, меняется в `js/config.js`).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки.
2. В репозитории откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Подключение общей базы (Supabase), чтобы ученик и учитель работали с разных устройств

GitHub Pages умеет показывать только файлы, поэтому для общих данных нужен бесплатный Supabase.

1. Зарегистрируйтесь на <https://supabase.com> и создайте проект (**New project**).
2. Откройте **SQL Editor → New query**, вставьте содержимое файла `supabase/schema.sql` и нажмите **Run**.
3. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon public**.
4. Вставьте их в `js/config.js`:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
   Ключ `anon` можно хранить в публичном репозитории: доступ к данным защищён правилами из `schema.sql`.
5. (Рекомендуется) **Authentication → Providers → Email**: выключите **Confirm email**, чтобы ученики входили сразу после регистрации.
   Если подтверждение оставить включённым, в **Authentication → URL Configuration** укажите адрес сайта на GitHub Pages.
6. Учитель регистрируется на сайте как обычный пользователь. Затем в **SQL Editor** выполните (со своим e-mail):
   ```sql
   update public.profiles set role = 'teacher'
     where id = (select id from auth.users where email = 'teacher@example.com');
   ```
   После повторного входа откроется кабинет учителя.

## Проверка заданий и сайта

```bash
npm run check   # тесты проверки ответов + проверка всех 1440 заданий
npm run e2e     # открывает все 36 тестов в Chrome + сценарий ученик → учитель → ученик
```

## Как добавить или изменить задания

Задания лежат в `data/units/u01.js` … `u12.js`. Типы заданий описаны в `CLAUDE.md`.
После изменений запустите `npm run check`: в каждом уроке должно быть 26 практических заданий, 10 по теории и 4 текста.
Не вставляйте и не удаляйте задания в середине урока, по которому ученики уже работают: ответы привязаны к номеру задания в группе.
